# 影之刃零下指嘲讽动作 MOD

版本：0.5.4

将《艾尔登法环》原版下指嘲讽动作移植到《影之刃零》。按 **O** 播放，动作期间可用 **WASD** 平滑转向、鼠标转动镜头，按 **Backspace** 提前取消。

## 实现方式

原版动作经过骨骼重定向，制作为匹配游戏骨架的原生 AnimSequence，通过 PAK、UTOC、UCAS 动画容器加载。UE4SS Lua 脚本负责按键触发、动作播放、输入限制和结束恢复，使用角色现有模型播放动画。

动作期间限制移动、攻击和闪避。镜头方向与灵敏度根据正常游玩时的鼠标输入自动校准；
